### [ToastyReplay](https://github.com/ToastexGD/ToastyReplay)
Geometry Dash's macro and replay bot, built with showcasers in mind.

</td>

- Frame perfect recording in the native TTR2 (soon to be TTR3) format, with legacy GDR and TTR support
- Converts macros from 30+ other replay bots so old runs work on my bot
- A full timeline editor, for fixing inputs that may somehow have been broken
- Video rendering built in through FFmpeg, no separate recorder needed (also supports the .exe)
- Vanilla, CBS, and CBF accuracy modes, with 50+ built in tools.
